# Проверка редактора и восстановления связи

26 сентября 2026 года. Проверки выполнены в отдельной базе и приложении на порту 8181.

- Сервер: 53 теста, 412 утверждений. Проверены доступ по коду и его истечение, чужие черновики, форма JSON, ошибочные переходы, недостижимые шаги, конфликт сохранения, неизменяемость публикации, закрепление версии попытки и отдельная проба без наград.
- Браузер: все 21 локальные проверки прошли по итогам общего и повторных целевых прогонов. В первом общем прогоне два утверждения требовали обновления: старый текст ошибки связи и способ воспроизведения отказа CSRF в Chromium. После исправления оба пройдены. Отдельная публичная проверка в локальном прогоне пропускается.
- Через интерфейс добавлен новый шаг, настроен переход, сохранён черновик, выполнена проба на 100 баллов, опубликована новая версия и открыта в обучении. Проверены ширины 390, 768 и 1366, сохранение после перезагрузки и предупреждение о несохранённых изменениях.
- Через HTTP проверены настоящий отказ без CSRF, два одновременных сохранения (200/409) и два одновременных запроса публикации (одна версия).
- Проверены потеря сети и восстановление, единичный отказ фонового запроса, просрочка после 37 секунд без сети, обновление CSRF с однократным повтором отклонённого запроса. Автоматический повтор сетевых ошибок для изменяющих запросов не добавлен.
- При просмотре кода исправлены обработка числовых идентификаторов шагов, описание закреплённой версии в окне проверки, отделение ошибок фоновых запросов от ошибок действий и защита от позднего ответа после смены экрана.

Причина «застрявшего» сообщения: прежний обработчик уведомлений записывал ошибку, но не снимал её при следующем успешном запросе. В доступном журнале Aeza за шесть часов ошибок 5xx у приложения не обнаружено; API и web не перезапускались и не завершались из-за нехватки памяти. Причина первоначального краткого обрыва на устройстве пользователя по этим данным не установлена.

Отчёты: `tmp/editor-php-final.log`, `tmp/editor-all-browser.log`, `tmp/editor-final-browser.log`, `tmp/editor-targeted.log`. Неудачные промежуточные прогоны сохранены для прослеживаемости. Снимки редактора: `docs/evidence/editor-390.png`, `editor-768.png`, `editor-1366.png`.

Пределы проверки: браузер Chrome 153 на Windows, учебные данные и правила двух существующих смен. Предметное согласование сценария остаётся за методистом; проверка переходов не доказывает правильность рабочих алгоритмов. Именных учётных записей методистов и совместного редактирования текста нет. Проба после перезагрузки запускается заново, черновик сохраняется.
