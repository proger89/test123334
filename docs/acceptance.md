# Проверка версии 4.1

Проверено локально 25 сентября 2026 года. Это работающий демонстрационный тренажёр, без внешней модели ИИ и без подключения к системам перевозчика.

## Соответствие обязательным функциям

| Требование | Реализация | Проверка |
|---|---|---|
| Профиль, навыки и уровни | Псевдоним, портрет, история, четыре уровня, последние пять наблюдений по каждому сценарию, версии и режиму | API, браузер, проверка истории свыше 100 попыток |
| Нелинейные сценарии | Два сценария JSON, условия доступности, независимые обращения, версии | Правильные пути, грубость, обещание, прерванное обращение, места есть/нет, разные порядки сообщения |
| Таймеры с последствиями | Скрытое появление багажа, сроки 45/35 секунд, пауза только в обучении | Просрочка, запоздалый запрос, обновление страницы, восстановление обработчика |
| Лояльность и безопасность | Две отдельные шкалы, критическая ошибка не компенсируется общением | Точные ожидаемые оценки и запрет положительного процента безопасности при критической ошибке |
| Достижения и испытание | Четыре достижения, две проверки за 24 часа, временные +20 | Повторы, результаты до вступления, обучение, однократная награда |
| Три рейтинга | Бригада, депо, компания, три вымышленные бригады | Все фильтры и 220 баллов после двух проверок в испытании |
| Разбор каждого решения | Выбор, объяснение, последствия, критерии, ссылка на страницу PDF | Обе браузерные цепочки; 8 записей первого правильного пути |
| Три вида уведомлений | Новый сценарий, испытание, окончание бонуса | Прочтение и переход; реальный бонус 90 секунд и предупреждение |
| Аналитика прохождений | Фактическая история, выполненные пункты, режим и версия | Данные обучения не дают рейтинговых очков; повтор не удваивает результат |

## Автоматические проверки

Сервер: 30 содержательных проверок движка, PostgreSQL и HTTP. Отдельная база `vsm_test`. Сценарии проверяются JSON Schema при публикации; неизвестные операции отклоняются. Новая версия доступна для обучения, а начатая попытка и рейтинговая версия сохраняются.

Браузер: 7 проверок в Microsoft Edge. Пройдены обе обязательные цепочки: две успешные смены с прогрессом, достижениями и тремя рейтингами; критическая ошибка, повторное обучение, успешная проверка. Проверены ширины 390, 768 и 1366, загрузка изображений, отсутствие горизонтального переполнения, восстановление паузы после обновления страницы, клавиатура в окне подготовки. Отключение сети выводит русское сообщение; после восстановления связи смена остаётся на паузе и сообщение исчезает. Ошибок JavaScript в основном пути нет. Интерактивный проход дополнительно выполнен во встроенном браузере Codex.

Десять одинаковых одновременных HTTP-команд вернули один и тот же ответ и применили действие один раз. Другая сессия получает 404 для чужой попытки; изменение без CSRF получает 419. Экспорт требует отдельный ключ только для чтения. Повтор с другим содержимым под тем же ключом получает 409.

Истечение 90-секундного бонуса проверено по реальному времени. После 36 секунд без обработчика просроченная проверка завершилась критической ошибкой при восстановлении. Полная остановка и повторный запуск отдельного приложения сохранили профиль и прогресс. Первоначальный запуск отдельного проекта выполнен на новом томе. Исходные файлы в Downloads и чужие контейнеры/тома не менялись.

## Быстродействие и запуск

На локальном Docker: 90 игровых действий, десять одновременных сессий. p95 — 131,5 мс, максимальный ответ — 142,1 мс. Первый полезный экран в последней браузерной проверке — 138 мс; в режиме разработки — 284 мс. Это локальные измерения, без эмуляции медленной сети; они не являются оценкой работы на сервере заказчика.

В обычном запуске доступны web, api, worker и db; init завершается после подготовки. API проверяется через FastCGI, обработчик — по свежему времени последней обработки. Образы закреплены digest, библиотеки — lock-файлами. В режиме разработки проверены выдача Vite через тот же адрес, API и обновление исходников Windows через наблюдение за изменением файлов.

Повторяемые команды находятся в README. Полные машинные отчёты после запуска: `tmp/tests.log`, `tmp/browser-results.json`, `tmp/http-acceptance.json`. Снимки интерфейса сохранены в `docs/evidence/`.

## Ограничения

- Рабочие алгоритмы, секунды и штрафы учебной модели не согласованы как норматив перевозчика. Полного регламента транспортной безопасности в исходных материалах нет.
- Бригады, депо и имена в примерах вымышлены. Интеграционный API готов к подключению, реальная кадровая система не подключена.
- Доступ к гостевому профилю сохраняется в этом браузере. После очистки данных сайта или 30 дней без входа самостоятельного восстановления нет.
- Интерфейс проверен в Edge и встроенном Chromium. Safari, Firefox, физические мобильные устройства и нагрузка больше десяти одновременных сессий отдельно не проверялись.
- Для игры после сборки интернет не нужен. Первое скачивание образов и зависимостей требует сети.

При окончательном просмотре исправлены: учёт результатов до вступления в ту же секунду и начисление по времени завершения, блокировка вступления вместе с завершением попытки, порядок карточек, сохранение срока при конфликте, точность аналитики при длинной истории, сообщения об ошибках, фокус клавиатуры и обновление файлов Windows. Игровая политика находится в Engine, HTTP и сохранение отделены; команды, шаги, действия и статусы представлены явными типами.
