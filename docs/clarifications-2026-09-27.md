# Повторная проверка замечаний

Основание: [«Уточнения»](https://docs.google.com/document/d/1NLF1OFau12lMZJ-_HvDUjRYjDvSr5Ois/edit). Исходный документ сохранён без изменений.

На снимках видны прежние названия наград и старый расчёт общей оценки пяти попыток. Адрес на снимке — локальный. Это признаки прежней сборки; определить по снимку, обновлялся ли контейнер на компьютере участницы, нельзя. Теперь интерфейс показывает номер сборки, а README отдельно объясняет обновление файлов и контейнеров без удаления данных.

| Замечание | Изменение |
|---|---|
| Результаты в истории стоят на разном расстоянии | Общие колонки названия, результата и перехода; на телефоне результат под названием |
| После успеха остаётся критическая ошибка | Последняя полная смена показывается отдельно от истории; проверяется последовательность из пяти попыток с ошибкой в четвёртой и успехом в пятой |
| Неясно, почему успешное упражнение не исправляет оценку | В результате упражнения прямо написано, что нужна новая полная проверка. Обучение и проверка также учитываются отдельно |
| Названия навыков сокращены | В интерфейсе полные названия; прежние ключи сохранённых результатов остаются для совместимости |
| Неполученные достижения не различимы | У полученных цветной значок и выделенная рамка, у неполученных приглушённый значок, пунктирная рамка и подпись. Условия читаются в обоих состояниях |
| В профиле нет результатов | Баллы, уровень, четыре достижения и три последние смены. Профиль обновляется при входе и во время просмотра, в том числе после действий в другой вкладке |
| Непонятно, где проверять временную награду | В README и публичном прогрессе дан путь к локальной демонстрации на 90 секунд |
| Непонятное название второго сценария | В интерфейсе исходная версия называется «Багаж без владельца». Сохранённое определение сценария не переписывается |
| Успешная смена не заканчивается | После двух обязательных действий сервер выполняет существующий завершающий переход и сохраняет итог в одной транзакции. Через две секунды открывается разбор |
| Два разных действия «Завершить» | Кнопка раннего выхода называется «Прервать смену» или «Прервать упражнение»; перед выходом есть предупреждение о незачёте |

Автоматическое завершение относится к полной исходной версии второго сценария. Предварительный просмотр редактора и новые версии используют свои переходы. Повторный запрос возвращает прежний ответ; результат и награды не начисляются повторно. Старые завершённые смены не пересчитываются. Приостановленная готовая смена завершится после продолжения.

Регистрация, правила рейтинга, реальные кадровые данные и предметное согласование алгоритмов в эти изменения не входят.

## Результат проверки 27 сентября

- Сервер: 58 тестов, 485 проверок. В том числе оба порядка действий в обучении и проверке, повтор запроса, прежняя готовая попытка, продолжение после паузы и новая успешная смена после критической ошибки.
- Браузер: проверены 31 локальный случай. Основной прогон дал 26 успешных проверок; четыре проверки обновлены под подтверждение выхода и завершение опубликованной учебной версии и повторно прошли. Ещё одна новая проверка подтверждает, что уведомление об обновлении не прерывает смену. Две проверки, предназначенные для публичного сервера, локально пропущены.
- Проверка двух вкладок: баллы и достижения обновились в открытом профиле без перезагрузки. Проверены ширины 390, 768 и 1366 пикселей, горизонтальной прокрутки нет.
- Временная награда: проверено настоящее ожидание 90 секунд, предупреждение, истечение и пересчёт рейтинга.
- HTML требует перепроверки, файл номера сборки не сохраняется в кэше, отсутствующий файл интерфейса возвращает 404. Новая сборка предлагается без автоматической перезагрузки.
- Документ ТЗ пересобран в DOCX и PDF; последняя страница с изменённым правилом просмотрена после преобразования.

Снимки профиля: [390 пикселей](evidence/clarifications-profile-390.png), [768 пикселей](evidence/clarifications-profile-768.png), [1366 пикселей](evidence/clarifications-profile-1366.png).

Исторические результаты не пересчитываются. Успешное упражнение не заменяет полную проверку. Автоматическое завершение второй смены не меняет авторские переходы новых версий из редактора. Эти различия сохранены намеренно.
